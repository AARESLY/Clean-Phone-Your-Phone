Clean Phone - Your Phone is a lightweight, zero-overhead Android utility for automatic download organization, deep system cache cleaning, and instant memory boosting.

Key Features:
• Real-Time Inotify Download Organizer: Uses Linux kernel inotify file-events with 0% battery consumption. No continuous polling loops.
• Automatic Categorization: Sorts downloads into Images, Documents, Archives, Code & Notes, Audio, and Videos.
• One-Tap Disorganizer: Instantly restore organized files back to root directory whenever needed.
• Deep Cache Cleaner: Instant batch clearing for rooted devices, and automated Accessibility scanning for non-rooted devices.
• App Closer: Reclaim RAM by terminating background apps in one click.
• Light & Dark Modes: Modern high-contrast UI tailored for day and night.
• 100% Offline & Private: No tracking, no analytics, no external servers.
